## 7.0 How to use this file

* The DDL is split into three **independent deployables**: §7.2–7.3 run on the **control plane** cluster, §7.4–7.14 run on **every data-plane shard**, §7.15 runs on the **audit** cluster; §7.16 contains helper SQL and query patterns. §7.1 (extensions, roles, helpers) runs on all three.
* Execute as `tabula_migrator` (owner/BYPASSRLS). In production these blocks are split into numbered migration files ([27](27-data-flows-transactions-migrations.md)); here they are grouped by domain for reading.
* Target: **PostgreSQL 16** with `pg_partman` ≥ 5.0, `pg_trgm`, `btree_gin`, `pgcrypto`, ICU collations (all available on Amazon RDS / Aurora PostgreSQL 16).
* Every `-- Q:` comment lists the **expected query patterns** the indexes on that table are designed for. If you add a query that is not listed, add (or justify the absence of) an index.

### 7.0.1 Conventions

| Topic | Convention | Why |
|---|---|---|
| Primary keys | `id uuid` — **UUIDv7 generated by the application**; `DEFAULT public.uuidv7()` only as a safety net | IDs exist before insert (outbox, idempotency, optimistic UI); time-ordered B-tree inserts. |
| Enumerations | **`text` + `CHECK (col IN (…))`**, not PostgreSQL `ENUM` types | Removing an enum label is impossible without recreating the type and rewriting every column that uses it; a value added with `ALTER TYPE … ADD VALUE` cannot be used in the same transaction that adds it (awkward for transactional migrations); enum changes must be rolled out to N shards in lockstep; CHECK constraints can be replaced with `NOT VALID` + `VALIDATE CONSTRAINT` online, are visible in `\d`, and cost only a few bytes more than a 4-byte enum for short labels. |
| Timestamps | `timestamptz`, UTC, `DEFAULT now()`; `updated_at` maintained by the application (no triggers, see [04 §6.28](04-database-architecture.md)) | |
| Soft delete | `deleted_at timestamptz`, `deleted_by uuid`, `deletion_batch_id uuid` (→ `data.deletion_batches`) | Trash/restore as a unit ([22](22-audit-history-undo-trash.md)). |
| Uniqueness of names | Partial unique indexes `… WHERE deleted_at IS NULL`, case-insensitive via `lower(name)` | Allows "delete then recreate same name"; trash restore detects conflicts and renames. |
| Tenant column | `workspace_id uuid NOT NULL` on **every** data-plane table; `org_id` on org-scoped control-plane tables | RLS + workspace moves (`COPY … WHERE workspace_id = $1`). |
| Foreign keys | Declared **within a plane** on metadata tables. **Not** declared on hot/huge tables (`records`, `record_links`, sidecars, `base_changes`, `outbox_events`, revisions, runs) nor into time-partitioned tables. No cross-plane/cross-shard FKs. | Avoids `FOR KEY SHARE` multixact contention on parent rows during bulk writes, keeps purges/partition drops cheap; integrity by the write path + nightly reconciliation ([04 §6.27](04-database-architecture.md)). |
| `ON DELETE` | Metadata children `CASCADE` from their container (hard deletes are purge-only, after children data is gone); references to *peers* use `SET NULL` or `RESTRICT` | |
| JSONB | Only per the policy in [04 §6.8](04-database-architecture.md); config docs carry `…_schema_version smallint` and `CHECK (jsonb_typeof(…) = 'object')` | |
| Secrets | `bytea` ciphertext + `key_id text` + `dek_ciphertext bytea` + `dek_version int` (envelope encryption) — never plaintext; token secrets stored as SHA-256 `bytea` | [04 §6.17–6.18](04-database-architecture.md) |
| Ordering keys | `text COLLATE "C"` fractional index strings (base62 lexorank) | Byte-order comparison is what fractional indexing assumes. |
| Naming | tables plural snake_case; indexes `<table>_<cols>_idx`, unique `_uq`, partial suffix describes predicate | |

## 7.1 Extensions, roles and shared helpers (all clusters)

```sql
-- ============================================================================
-- 7.1.1 Extensions
-- ============================================================================
CREATE EXTENSION IF NOT EXISTS pgcrypto;            -- gen_random_uuid(), digest()
CREATE EXTENSION IF NOT EXISTS pg_trgm;             -- trigram search on names / text sidecar
CREATE EXTENSION IF NOT EXISTS btree_gin;           -- composite GIN (uuid + tsvector)
CREATE EXTENSION IF NOT EXISTS pg_stat_statements;
CREATE SCHEMA IF NOT EXISTS partman;
CREATE EXTENSION IF NOT EXISTS pg_partman SCHEMA partman;

-- ============================================================================
-- 7.1.2 Roles (idempotent creation is done by the infra bootstrap; shown here for reference)
-- Passwords / IAM auth are configured outside SQL (Secrets Manager).
-- ============================================================================
DO $$
BEGIN
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'tabula_owner')    THEN CREATE ROLE tabula_owner NOLOGIN; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'tabula_migrator') THEN CREATE ROLE tabula_migrator LOGIN BYPASSRLS IN ROLE tabula_owner; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'tabula_partman')  THEN CREATE ROLE tabula_partman LOGIN IN ROLE tabula_owner; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'app_rw')          THEN CREATE ROLE app_rw LOGIN; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'app_admin')       THEN CREATE ROLE app_admin LOGIN; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'app_readonly')    THEN CREATE ROLE app_readonly LOGIN; END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'tabula_relay')    THEN CREATE ROLE tabula_relay LOGIN; END IF;
END $$;
-- On RDS: GRANT rds_replication TO tabula_relay;   (self-managed: ALTER ROLE tabula_relay REPLICATION;)

ALTER ROLE app_rw       SET statement_timeout = '15s';
ALTER ROLE app_rw       SET lock_timeout = '3s';
ALTER ROLE app_rw       SET idle_in_transaction_session_timeout = '10s';
ALTER ROLE app_admin    SET statement_timeout = '5min';
ALTER ROLE app_admin    SET idle_in_transaction_session_timeout = '60s';
ALTER ROLE app_readonly SET default_transaction_read_only = on;
ALTER ROLE app_readonly SET statement_timeout = '10min';

-- ============================================================================
-- 7.1.3 UUIDv7 polyfill for PG16 (PG18 ships pg_catalog.uuidv7(), which takes precedence
-- in name resolution because pg_catalog is searched first). Application generation is canonical.
-- Layout: 48-bit unix ms | ver(7) | 12 random | var(10) | 62 random.
-- ============================================================================
CREATE OR REPLACE FUNCTION public.uuidv7() RETURNS uuid
LANGUAGE sql VOLATILE PARALLEL SAFE AS $$
  SELECT encode(
           set_bit(
             set_bit(
               overlay(uuid_send(gen_random_uuid())
                       PLACING substring(int8send(floor(extract(epoch FROM clock_timestamp()) * 1000)::bigint) FROM 3)
                       FROM 1 FOR 6),
               52, 1),
             53, 1),
           'hex')::uuid;
$$;

-- Extract the embedded timestamp: used to prune time-partitioned tables when looking up by id.
CREATE OR REPLACE FUNCTION public.uuidv7_time(u uuid) RETURNS timestamptz
LANGUAGE sql IMMUTABLE STRICT PARALLEL SAFE AS $$
  SELECT to_timestamp((('x' || lpad(substr(replace(u::text, '-', ''), 1, 12), 16, '0'))::bit(64)::bigint) / 1000.0);
$$;

-- ============================================================================
-- 7.1.4 RLS policy template (used by every schema)
-- One permissive policy for request-path roles keyed on a context expression,
-- one explicit "all rows" policy for app_admin. FORCE so the table owner is also subject.
-- ============================================================================
CREATE OR REPLACE PROCEDURE public.apply_rls_policy(p_table regclass, p_predicate text)
LANGUAGE plpgsql AS $$
BEGIN
  EXECUTE format('ALTER TABLE %s ENABLE ROW LEVEL SECURITY', p_table);
  EXECUTE format('ALTER TABLE %s FORCE ROW LEVEL SECURITY', p_table);
  EXECUTE format('DROP POLICY IF EXISTS tenant_rw ON %s', p_table);
  EXECUTE format('DROP POLICY IF EXISTS admin_all ON %s', p_table);
  EXECUTE format('CREATE POLICY tenant_rw ON %s AS PERMISSIVE FOR ALL TO app_rw, app_readonly USING (%s) WITH CHECK (%s)',
                 p_table, p_predicate, p_predicate);
  EXECUTE format('CREATE POLICY admin_all ON %s AS PERMISSIVE FOR ALL TO app_admin USING (true) WITH CHECK (true)', p_table);
END $$;

-- Grant DML on a *parent* table only (never on partitions: a partition queried directly
-- would bypass the parent's RLS policies).
CREATE OR REPLACE PROCEDURE public.grant_app_dml(p_table regclass)
LANGUAGE plpgsql AS $$
BEGIN
  EXECUTE format('GRANT SELECT, INSERT, UPDATE, DELETE ON %s TO app_rw, app_admin', p_table);
  EXECUTE format('GRANT SELECT ON %s TO app_readonly', p_table);
END $$;
```

## 7.3 Control plane — tables

### 7.3.1 Organizations

```sql
-- ----------------------------------------------------------------------------
-- core.organizations — tenant root.
-- Q: by id (every request, cached); by slug (vanity URL / SSO discovery); admin list by status.
-- ----------------------------------------------------------------------------
CREATE TABLE core.organizations (
  id                       uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  name                     text        NOT NULL CHECK (length(name) BETWEEN 1 AND 200),
  slug                     text        NOT NULL CHECK (slug ~ '^[a-z0-9][a-z0-9-]{1,62}$'),
  kind                     text        NOT NULL DEFAULT 'standard'
                                       CHECK (kind IN ('personal','standard','enterprise')),
  status                   text        NOT NULL DEFAULT 'active'
                                       CHECK (status IN ('active','suspended','pending_deletion','deleted')),
  data_region              text        NOT NULL DEFAULT 'us-east-1',
  billing_email            text,
  kms_key_arn              text,                       -- dedicated CMK (Enterprise / BYOK); NULL = region CMK
  settings                 jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(settings) = 'object'),
  settings_schema_version  smallint    NOT NULL DEFAULT 1,
  created_by               uuid,                       -- core.users.id (no FK: creator may be erased)
  created_at               timestamptz NOT NULL DEFAULT now(),
  updated_at               timestamptz NOT NULL DEFAULT now(),
  suspended_at             timestamptz,
  deleted_at               timestamptz,
  purge_after              timestamptz,
  CHECK ((status = 'deleted') = (deleted_at IS NOT NULL))
);
CREATE UNIQUE INDEX organizations_slug_uq ON core.organizations (slug) WHERE deleted_at IS NULL;
CREATE INDEX organizations_status_idx     ON core.organizations (status) WHERE status <> 'active';
CREATE INDEX organizations_purge_idx      ON core.organizations (purge_after) WHERE purge_after IS NOT NULL;

-- ----------------------------------------------------------------------------
-- core.organization_domains — verified email domains (SSO enforcement, auto-join).
-- Q: by domain at login/signup ("is acme.com claimed & SSO-enforced?"); list per org.
-- ----------------------------------------------------------------------------
CREATE TABLE core.organization_domains (
  id                        uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  org_id                    uuid        NOT NULL REFERENCES core.organizations(id) ON DELETE CASCADE,
  domain                    text        NOT NULL CHECK (domain = lower(domain) AND domain ~ '^[a-z0-9.-]+\.[a-z]{2,}$'),
  verification_method       text        NOT NULL DEFAULT 'dns_txt' CHECK (verification_method IN ('dns_txt','http_file','manual')),
  verification_token_hash   bytea       NOT NULL,    -- SHA-256 of the TXT record value
  status                    text        NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','verified','failed','revoked')),
  verified_at               timestamptz,
  last_checked_at           timestamptz,
  auto_join                 boolean     NOT NULL DEFAULT false,   -- users with this domain may self-join as member
  sso_enforced              boolean     NOT NULL DEFAULT false,
  created_by                uuid,
  created_at                timestamptz NOT NULL DEFAULT now(),
  updated_at                timestamptz NOT NULL DEFAULT now(),
  CHECK ((status = 'verified') = (verified_at IS NOT NULL)),
  CHECK (NOT sso_enforced OR status = 'verified')
);
-- A domain can be verified by exactly one org.
CREATE UNIQUE INDEX organization_domains_verified_uq ON core.organization_domains (domain) WHERE status = 'verified';
CREATE UNIQUE INDEX organization_domains_org_domain_uq ON core.organization_domains (org_id, domain);

-- ----------------------------------------------------------------------------
-- core.users — global identity.
-- Q: by id (hot, cached); by normalized email (login, invite, SCIM); member directory joins.
-- ----------------------------------------------------------------------------
CREATE TABLE core.users (
  id                    uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  email                 text        NOT NULL CHECK (length(email) BETWEEN 3 AND 320),
  email_normalized      text        NOT NULL CHECK (email_normalized = lower(email_normalized)),
  email_verified_at     timestamptz,
  display_name          text        NOT NULL DEFAULT '' CHECK (length(display_name) <= 200),
  avatar_object_key     text,
  locale                text        NOT NULL DEFAULT 'en-US',
  time_zone             text        NOT NULL DEFAULT 'UTC',
  status                text        NOT NULL DEFAULT 'active'
                                    CHECK (status IN ('pending','active','deactivated','erased')),
  is_bot                boolean     NOT NULL DEFAULT false,   -- system principals rendered as users (e.g. "Automation")
  last_login_at         timestamptz,
  created_at            timestamptz NOT NULL DEFAULT now(),
  updated_at            timestamptz NOT NULL DEFAULT now(),
  deactivated_at        timestamptz,
  erased_at             timestamptz                          -- GDPR erasure: PII replaced with tombstone values
);
CREATE UNIQUE INDEX users_email_uq       ON core.users (email_normalized) WHERE status <> 'erased';
CREATE INDEX users_display_name_trgm_idx ON core.users USING gin (lower(display_name) gin_trgm_ops);

-- ----------------------------------------------------------------------------
-- core.organization_members — user <-> org with org role.
-- Q: (org_id, user_id) membership check (hot, cached in permission snapshot);
--    list members of org (admin UI, SCIM); list orgs of a user (home screen).
-- ----------------------------------------------------------------------------
CREATE TABLE core.organization_members (
  org_id          uuid        NOT NULL REFERENCES core.organizations(id) ON DELETE CASCADE,
  user_id         uuid        NOT NULL REFERENCES core.users(id) ON DELETE CASCADE,
  role            text        NOT NULL CHECK (role IN ('owner','admin','billing_admin','member','guest')),
  status          text        NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended','deactivated')),
  source          text        NOT NULL DEFAULT 'manual' CHECK (source IN ('manual','invite','scim','sso_jit','domain_auto_join','org_creation')),
  scim_external_id text,
  is_billable     boolean     NOT NULL DEFAULT true,
  joined_at       timestamptz NOT NULL DEFAULT now(),
  created_at      timestamptz NOT NULL DEFAULT now(),
  updated_at      timestamptz NOT NULL DEFAULT now(),
  deactivated_at  timestamptz,
  PRIMARY KEY (org_id, user_id)
);
CREATE INDEX organization_members_user_idx ON core.organization_members (user_id) WHERE status = 'active';
CREATE INDEX organization_members_role_idx ON core.organization_members (org_id, role) WHERE role IN ('owner','admin','billing_admin');
CREATE UNIQUE INDEX organization_members_scim_uq ON core.organization_members (org_id, scim_external_id) WHERE scim_external_id IS NOT NULL;

-- ----------------------------------------------------------------------------
-- core.organization_policies — Enterprise policy settings, one row per policy key.
-- Q: all policies of an org (cached with org settings); single key on enforcement paths.
-- ----------------------------------------------------------------------------
CREATE TABLE core.organization_policies (
  org_id          uuid        NOT NULL REFERENCES core.organizations(id) ON DELETE CASCADE,
  policy_key      text        NOT NULL CHECK (policy_key IN (
                     'sharing','ai','retention','ip_allowlist','session','export','integrations',
                     'invites','oauth_app_policy','api_tokens','mfa','data_residency','attachments')),
  value           jsonb       NOT NULL CHECK (jsonb_typeof(value) = 'object'),
  schema_version  smallint    NOT NULL DEFAULT 1,
  version         integer     NOT NULL DEFAULT 1,             -- optimistic concurrency for admin UI
  updated_by      uuid,
  updated_at      timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (org_id, policy_key)
);
```

### 7.3.2 Identity, MFA, sessions

```sql
-- ----------------------------------------------------------------------------
-- core.user_identities — login methods.
-- Q: (provider, connection, subject) at OAuth/SSO login; by user_id (account settings);
--    password identity by user_id at password login.
-- ----------------------------------------------------------------------------
CREATE TABLE core.user_identities (
  id                 uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  user_id            uuid        NOT NULL REFERENCES core.users(id) ON DELETE CASCADE,
  provider           text        NOT NULL CHECK (provider IN ('password','google','microsoft','apple','github','saml','oidc')),
  sso_connection_id  uuid,       -- FK added after core.sso_connections is created
  subject            text        NOT NULL,         -- provider subject; for 'password' = user_id::text
  email_at_provider  text,
  password_hash      text,       -- Argon2id PHC string; only for provider='password'
  password_changed_at timestamptz,
  profile            jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(profile) = 'object'),  -- non-secret claims snapshot
  last_used_at       timestamptz,
  created_at         timestamptz NOT NULL DEFAULT now(),
  updated_at         timestamptz NOT NULL DEFAULT now(),
  CHECK ((provider = 'password') = (password_hash IS NOT NULL)),
  CHECK (password_hash IS NULL OR password_hash LIKE '$argon2id$%'),
  CHECK ((provider IN ('saml','oidc')) = (sso_connection_id IS NOT NULL))
);
CREATE UNIQUE INDEX user_identities_subject_uq ON core.user_identities (provider, sso_connection_id, subject) NULLS NOT DISTINCT;
CREATE UNIQUE INDEX user_identities_password_uq ON core.user_identities (user_id) WHERE provider = 'password';
CREATE INDEX user_identities_user_idx ON core.user_identities (user_id);

-- ----------------------------------------------------------------------------
-- core.user_mfa_factors — TOTP (encrypted secret), WebAuthn credentials, recovery codes (hashed).
-- Q: factors of a user at login; WebAuthn credential id lookup (usernameless / passkey flow).
-- ----------------------------------------------------------------------------
CREATE TABLE core.user_mfa_factors (
  id                        uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  user_id                   uuid        NOT NULL REFERENCES core.users(id) ON DELETE CASCADE,
  kind                      text        NOT NULL CHECK (kind IN ('totp','webauthn','recovery_codes')),
  label                     text        NOT NULL DEFAULT '' CHECK (length(label) <= 100),
  -- TOTP secret, envelope-encrypted with the platform DEK (AAD = user_id|factor id|'totp')
  totp_secret_ciphertext    bytea,
  key_id                    text,
  dek_ciphertext            bytea,
  dek_version               integer,
  -- WebAuthn
  webauthn_credential_id    bytea,
  webauthn_public_key       bytea,      -- COSE key
  webauthn_sign_count       bigint      NOT NULL DEFAULT 0,
  webauthn_transports       text[],
  webauthn_aaguid           uuid,
  webauthn_backup_eligible  boolean,
  -- Recovery codes: Argon2id hashes; consumed codes removed from the array
  recovery_code_hashes      text[],
  confirmed_at              timestamptz,
  last_used_at              timestamptz,
  created_at                timestamptz NOT NULL DEFAULT now(),
  deleted_at                timestamptz,
  CHECK (kind <> 'totp'           OR (totp_secret_ciphertext IS NOT NULL AND key_id IS NOT NULL AND dek_ciphertext IS NOT NULL)),
  CHECK (kind <> 'webauthn'       OR (webauthn_credential_id IS NOT NULL AND webauthn_public_key IS NOT NULL)),
  CHECK (kind <> 'recovery_codes' OR recovery_code_hashes IS NOT NULL)
);
CREATE INDEX user_mfa_factors_user_idx ON core.user_mfa_factors (user_id) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX user_mfa_factors_webauthn_uq ON core.user_mfa_factors (webauthn_credential_id) WHERE webauthn_credential_id IS NOT NULL AND deleted_at IS NULL;
CREATE UNIQUE INDEX user_mfa_factors_recovery_uq ON core.user_mfa_factors (user_id) WHERE kind = 'recovery_codes' AND deleted_at IS NULL;

-- ----------------------------------------------------------------------------
-- core.user_preferences — UI prefs (not notification prefs).
-- Q: by user_id (bootstrap).
-- ----------------------------------------------------------------------------
CREATE TABLE core.user_preferences (
  user_id         uuid        PRIMARY KEY REFERENCES core.users(id) ON DELETE CASCADE,
  prefs           jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(prefs) = 'object'),
  schema_version  smallint    NOT NULL DEFAULT 1,
  updated_at      timestamptz NOT NULL DEFAULT now()
);

-- ----------------------------------------------------------------------------
-- core.sessions — opaque session tokens (SHA-256 hashed).
-- Q: by token_hash (every cookie request on Redis miss); active sessions of a user (revoke all);
--    expiry sweep.
-- ----------------------------------------------------------------------------
CREATE TABLE core.sessions (
  id                 uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  user_id            uuid        NOT NULL REFERENCES core.users(id) ON DELETE CASCADE,
  token_hash         bytea       NOT NULL CHECK (length(token_hash) = 32),
  auth_method        text        NOT NULL CHECK (auth_method IN ('password','oauth','saml','oidc','magic_link','support_impersonation')),
  mfa_level          text        NOT NULL DEFAULT 'none' CHECK (mfa_level IN ('none','mfa','phishing_resistant')),
  mfa_verified_at    timestamptz,
  sso_connection_id  uuid,
  org_id             uuid,       -- org that issued an SSO-bound session (policy enforcement)
  ip                 inet,
  user_agent         text        CHECK (length(user_agent) <= 1024),
  device_label       text,
  created_at         timestamptz NOT NULL DEFAULT now(),
  last_seen_at       timestamptz NOT NULL DEFAULT now(),  -- updated at most every 5 min
  idle_expires_at    timestamptz NOT NULL,
  expires_at         timestamptz NOT NULL,
  revoked_at         timestamptz,
  revoke_reason      text        CHECK (revoke_reason IN ('logout','admin','password_change','user_deactivated','sso_policy','suspicious','expired')),
  CHECK (idle_expires_at <= expires_at)
);
CREATE UNIQUE INDEX sessions_token_hash_uq ON core.sessions (token_hash);
CREATE INDEX sessions_user_active_idx      ON core.sessions (user_id) WHERE revoked_at IS NULL;
CREATE INDEX sessions_expires_idx          ON core.sessions (expires_at);
```

-- ----------------------------------------------------------------------------
-- core.api_tokens — PATs, service-account tokens, OAuth access tokens. Secret never stored.
-- Token string: t{pat|svc|oat}_<id base62>_<secret>; lookup by PK then constant-time compare.
-- Q: by id (auth on Redis miss); tokens of a user / service account (settings UI);
--    tokens of an oauth grant (revoke); expiry sweep.
-- ----------------------------------------------------------------------------
CREATE TABLE core.api_tokens (
  id                     uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  kind                   text        NOT NULL CHECK (kind IN ('pat','service_account','oauth_access')),
  org_id                 uuid        REFERENCES core.organizations(id) ON DELETE CASCADE,   -- required for service accounts
  user_id                uuid        REFERENCES core.users(id) ON DELETE CASCADE,
  service_account_id     uuid        REFERENCES core.service_accounts(id) ON DELETE CASCADE,
  oauth_grant_id         uuid        REFERENCES core.oauth_grants(id) ON DELETE CASCADE,
  name                   text        NOT NULL DEFAULT '' CHECK (length(name) <= 200),
  secret_hash            bytea       NOT NULL CHECK (length(secret_hash) = 32),   -- SHA-256(secret) (v1) / HMAC-SHA-256 (v2)
  hash_version           smallint    NOT NULL DEFAULT 1 CHECK (hash_version IN (1,2)),
  display_hint           text        NOT NULL,          -- e.g. 'tpat_…AbCd…wxYz' shown in UI
  scopes                 text[]      NOT NULL CHECK (cardinality(scopes) >= 1),
  resource_restrictions  jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(resource_restrictions) = 'object'),
  status                 text        NOT NULL DEFAULT 'active' CHECK (status IN ('active','revoked','expired')),
  expires_at             timestamptz,
  last_used_at           timestamptz,                    -- coarse (≤ 1 write / 5 min)
  last_used_ip           inet,
  created_by             uuid,
  created_at             timestamptz NOT NULL DEFAULT now(),
  revoked_at             timestamptz,
  revoked_by             uuid,
  CHECK (
       (kind = 'pat'             AND user_id IS NOT NULL AND service_account_id IS NULL AND oauth_grant_id IS NULL)
    OR (kind = 'service_account' AND service_account_id IS NOT NULL AND org_id IS NOT NULL AND user_id IS NULL AND oauth_grant_id IS NULL)
    OR (kind = 'oauth_access'    AND oauth_grant_id IS NOT NULL AND user_id IS NOT NULL AND expires_at IS NOT NULL)
  ),
  CHECK ((status = 'revoked') = (revoked_at IS NOT NULL))
);
CREATE INDEX api_tokens_user_idx      ON core.api_tokens (user_id) WHERE status = 'active' AND kind = 'pat';
CREATE INDEX api_tokens_svc_idx       ON core.api_tokens (service_account_id) WHERE service_account_id IS NOT NULL AND status = 'active';
CREATE INDEX api_tokens_grant_idx     ON core.api_tokens (oauth_grant_id) WHERE oauth_grant_id IS NOT NULL;
CREATE INDEX api_tokens_org_idx       ON core.api_tokens (org_id) WHERE org_id IS NOT NULL;
CREATE INDEX api_tokens_expiry_idx    ON core.api_tokens (expires_at) WHERE status = 'active' AND expires_at IS NOT NULL;

-- ----------------------------------------------------------------------------
-- data.base_runtime — hot counters, one row per base. Every write transaction of the base runs
--   UPDATE data.base_runtime SET change_seq = change_seq + 1, last_change_at = now()
--    WHERE base_id = $1 RETURNING change_seq;
-- as late as possible in the transaction; the row lock serializes commits per base and gives
-- base_changes a gap-free total order (D9/D10).
-- Q: point UPDATE … RETURNING per write tx; point SELECT for epochs (cached).
-- ----------------------------------------------------------------------------
CREATE TABLE data.base_runtime (
  base_id                   uuid        PRIMARY KEY REFERENCES data.bases(id) ON DELETE CASCADE,
  workspace_id              uuid        NOT NULL,
  change_seq                bigint      NOT NULL DEFAULT 0,
  perm_epoch                bigint      NOT NULL DEFAULT 1,
  schema_version            bigint      NOT NULL DEFAULT 1,
  automation_index_version  bigint      NOT NULL DEFAULT 1,  -- [proposed column, 14 §30]
  record_count              bigint      NOT NULL DEFAULT 0,  -- [proposed column, 06 §20] exact, incl. trashed until purge
  last_change_at            timestamptz,
  updated_at                timestamptz NOT NULL DEFAULT now()
) WITH (fillfactor = 50, autovacuum_vacuum_scale_factor = 0.0, autovacuum_vacuum_threshold = 500);

-- ----------------------------------------------------------------------------
-- data.tables — table metadata + per-table counters (next_field_slot, next_row_number).
-- Q: tables of a base (schema snapshot); by id; counter UPDATE … RETURNING on record insert / field create.
-- ----------------------------------------------------------------------------
CREATE TABLE data.tables (
  id                      uuid        PRIMARY KEY DEFAULT public.uuidv7(),
  workspace_id            uuid        NOT NULL,
  base_id                 uuid        NOT NULL REFERENCES data.bases(id) ON DELETE CASCADE,
  kind                    text        NOT NULL DEFAULT 'standard' CHECK (kind IN ('standard','contacts','sync')),
  name                    text        NOT NULL CHECK (length(name) BETWEEN 1 AND 200),
  description             text        NOT NULL DEFAULT '',
  icon                    text,
  primary_field_id        uuid,       -- FK added below (deferrable; circular with fields)
  order_key               text        COLLATE "C" NOT NULL,
  next_field_slot         smallint    NOT NULL DEFAULT 1 CHECK (next_field_slot BETWEEN 1 AND 32000),
  next_row_number         bigint      NOT NULL DEFAULT 1 CHECK (next_row_number >= 1),
  record_count            bigint      NOT NULL DEFAULT 0,      -- approximate (UI); exact limit check uses base_runtime
  tombstoned_slots        smallint[]  NOT NULL DEFAULT '{}',   -- [proposed column, 06 §16]
  restrictions            jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(restrictions) = 'object'),  -- incl. rowPolicies (Enterprise)
  settings                jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(settings) = 'object'),
  settings_schema_version smallint    NOT NULL DEFAULT 1,
  sidecars_enabled        boolean     NOT NULL DEFAULT false,  -- flipped when record_count ≥ INDEX_SIDECAR_THRESHOLD
  sync_source_id          uuid,       -- set when kind = 'sync' (FK added after data.sync_sources)
  created_by              uuid,
  created_at              timestamptz NOT NULL DEFAULT now(),
  updated_by              uuid,
  updated_at              timestamptz NOT NULL DEFAULT now(),
  deleted_at              timestamptz,
  deleted_by              uuid,
  deletion_batch_id       uuid,
  CHECK ((kind = 'sync') = (sync_source_id IS NOT NULL))
) WITH (fillfactor = 70);   -- counters are updated in place (HOT)
CREATE INDEX tables_base_idx ON data.tables (base_id, order_key) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX tables_base_name_uq ON data.tables (base_id, lower(name)) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX tables_contacts_uq ON data.tables (base_id) WHERE kind = 'contacts' AND deleted_at IS NULL;
CREATE INDEX tables_deletion_batch_idx ON data.tables (deletion_batch_id) WHERE deletion_batch_id IS NOT NULL;

-- ----------------------------------------------------------------------------
-- data.fields — field metadata. slot is unique per table and never reused.
-- Q: fields of a base (schema snapshot); by id; name uniqueness; fields with sidecar work pending;
--    config documents below current schema version (background rewrite).
-- ----------------------------------------------------------------------------

  config                  jsonb       NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(config) = 'object'),  -- options, precision, linkRelationId, inverseFieldId, formula…
  config_schema_version   smallint    NOT NULL DEFAULT 1,

  order_key               text        COLLATE "C" NOT NULL,     -- default field order (views override)
  is_computed             boolean     NOT NULL DEFAULT false,
  compute_state           text        NOT NULL DEFAULT 'ok' CHECK (compute_state IN ('ok','backfilling','error')),
  compute_error           jsonb,
  index_state             text        NOT NULL DEFAULT 'none'
                                      CHECK (index_state IN ('none','backfilling','ready','rebuilding','dropping')),  -- [proposed column, 06 §13.3]
  index_progress          jsonb,      -- [proposed column]
  conversion              jsonb,      -- [proposed column, 06 §15] {fromSlot,fromType,fromConfig,toSlot,longOperationId}
  created_by              uuid,
  created_at              timestamptz NOT NULL DEFAULT now(),
  updated_by              uuid,
  updated_at              timestamptz NOT NULL DEFAULT now(),

-- ----------------------------------------------------------------------------
-- data.records — record rows (D6; detail in 06). HASH(table_id) × 64. No declared FKs (hot path).
-- cells: user values keyed by slot ({"1":"Acme","4":1200}); computed: materialized computed values;
-- cell_meta: per-slot {seq, by, at}.
-- Q: (1) grid window: WHERE table_id=$1 AND deleted_at IS NULL ORDER BY manual_order, id LIMIT 200 (keyset)
--    (2) fetch by ids: WHERE table_id=$1 AND id = ANY($2)
--    (3) compiled JSONB predicates for tables below INDEX_SIDECAR_THRESHOLD (7.15.3)
--    (4) upsert by external_ref (sync/import); (5) trash list/restore by deletion_batch_id; (6) created-time sort.
-- Writes: single-row UPDATE of cells/computed/cell_meta/version (HOT-eligible); batched INSERT; soft delete.
-- ----------------------------------------------------------------------------
CREATE TABLE data.records (
  table_id           uuid        NOT NULL,
  id                 uuid        NOT NULL,                      -- UUIDv7 (rec_)
  workspace_id       uuid        NOT NULL,
  base_id            uuid        NOT NULL,
  row_number         bigint      NOT NULL,                      -- autonumber from tables.next_row_number
  manual_order       text        COLLATE "C" NOT NULL,          -- fractional index (table baseline order)
  cells              jsonb       COMPRESSION lz4 NOT NULL DEFAULT '{}'::jsonb,
  computed           jsonb       COMPRESSION lz4 NOT NULL DEFAULT '{}'::jsonb,
  cell_meta          jsonb       COMPRESSION lz4 NOT NULL DEFAULT '{}'::jsonb,
  version            bigint      NOT NULL DEFAULT 1,            -- If-Match / ETag
  external_ref       text        CHECK (length(external_ref) <= 512),   -- [proposed column] stable upsert key

  created_by         uuid,

  updated_at         timestamptz NOT NULL DEFAULT now(),
  updated_by         uuid,

  deleted_at         timestamptz,
  deleted_by         uuid,
  deletion_batch_id  uuid,
  PRIMARY KEY (table_id, id),
  CHECK (jsonb_typeof(cells) = 'object' AND jsonb_typeof(computed) = 'object' AND jsonb_typeof(cell_meta) = 'object'),
  CHECK ((deleted_at IS NULL) = (deletion_batch_id IS NULL))

-- ----------------------------------------------------------------------------
-- 7.14.1 Hash partitions (created once per shard; never by user actions).
-- ----------------------------------------------------------------------------
CREATE OR REPLACE PROCEDURE data.create_hash_partitions(p_parent regclass, p_modulus int, p_reloptions text DEFAULT NULL)
LANGUAGE plpgsql AS $$
DECLARE
  i        int;
  v_schema text;
  v_rel    text;
  v_name   text;
BEGIN
  SELECT n.nspname, c.relname INTO v_schema, v_rel
    FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace WHERE c.oid = p_parent;
  FOR i IN 0 .. p_modulus - 1 LOOP
    v_name := format('%s_p%s', v_rel, lpad(i::text, 2, '0'));
    EXECUTE format('CREATE TABLE IF NOT EXISTS %I.%I PARTITION OF %s FOR VALUES WITH (MODULUS %s, REMAINDER %s)%s',
                   v_schema, v_name, p_parent, p_modulus, i,
                   CASE WHEN p_reloptions IS NULL THEN '' ELSE ' WITH (' || p_reloptions || ')' END);
    -- privileges only on parents (RLS lives on the parent)
    EXECUTE format('REVOKE ALL ON %I.%I FROM PUBLIC, app_rw, app_admin, app_readonly', v_schema, v_name);
  END LOOP;
END $$;

CALL data.create_hash_partitions('data.records', 64,
  'fillfactor = 80, autovacuum_vacuum_scale_factor = 0.02, autovacuum_vacuum_threshold = 5000, autovacuum_analyze_scale_factor = 0.02, autovacuum_vacuum_cost_limit = 2000');
CALL data.create_hash_partitions('data.record_links', 32,
  'fillfactor = 90, autovacuum_vacuum_scale_factor = 0.05');

  'fillfactor = 85, autovacuum_vacuum_scale_factor = 0.05');

--   CALL partman.run_maintenance_proc();   hourly, as tabula_partman.
-- Partition-level reloptions are applied by the same maintenance job right after creation.

SELECT partman.create_parent(p_parent_table := 'data.outbox_events',        p_control := 'created_at', p_interval := '1 day',   p_premake := 7);

SELECT partman.create_parent(p_parent_table := 'data.automation_runs',      p_control := 'trigger_at', p_interval := '1 month', p_premake := 3);
SELECT partman.create_parent(p_parent_table := 'data.automation_step_runs', p_control := 'trigger_at', p_interval := '1 month', p_premake := 3);
SELECT partman.create_parent(p_parent_table := 'data.webhook_deliveries',   p_control := 'created_at', p_interval := '1 month', p_premake := 3);
SELECT partman.create_parent(p_parent_table := 'data.ai_invocations',       p_control := 'created_at', p_interval := '1 month', p_premake := 3);

UPDATE partman.part_config SET infinite_time_partitions = true, retention_keep_table = false,
       retention = CASE parent_table
         WHEN 'data.base_changes'         THEN '30 days'     -- BASE_CHANGES_RETENTION
         WHEN 'data.outbox_events'        THEN '3 days'
         WHEN 'data.record_revisions'     THEN '36 months'   -- max plan retention; shorter plans purged per tenant
         WHEN 'data.automation_runs'      THEN '12 months'
         WHEN 'data.automation_step_runs' THEN '12 months'
         WHEN 'data.webhook_deliveries'   THEN '3 months'
         WHEN 'data.ai_invocations'       THEN '13 months'
       END
 WHERE parent_table LIKE 'data.%';

-- automation_runs / step_runs: trigger_at may be slightly in the past (redelivered events) or, for
-- far-past events, older than the oldest partition; pg_partman's default partition catches those and an
-- alert fires if it is non-empty (the matcher rejects events older than 7 days anyway).

-- ----------------------------------------------------------------------------
-- 7.14.3 Grants (parents only) + RLS on every tenant table.
-- ----------------------------------------------------------------------------
DO $$
DECLARE r record;
BEGIN
  FOR r IN
    SELECT c.oid::regclass AS t
      FROM pg_class c
      JOIN pg_namespace n ON n.oid = c.relnamespace
     WHERE n.nspname = 'data' AND c.relkind IN ('r','p') AND NOT c.relispartition
       AND c.relname NOT LIKE 'template_%'
  LOOP
    CALL public.grant_app_dml(r.t);
    IF EXISTS (SELECT 1 FROM pg_attribute a WHERE a.attrelid = r.t AND a.attname = 'workspace_id' AND NOT a.attisdropped) THEN
      CALL public.apply_rls_policy(r.t, 'workspace_id = (SELECT data.current_workspace_id())');
    END IF;
  END LOOP;
END $$;

-- System prompt templates (workspace_id IS NULL) are readable by everyone, writable by nobody on the request path.
DROP POLICY IF EXISTS tenant_rw ON data.ai_prompt_templates;
CREATE POLICY tenant_read ON data.ai_prompt_templates FOR SELECT TO app_rw, app_readonly
  USING (workspace_id IS NULL OR workspace_id = (SELECT data.current_workspace_id()));
CREATE POLICY tenant_write ON data.ai_prompt_templates FOR INSERT TO app_rw
  WITH CHECK (workspace_id = (SELECT data.current_workspace_id()));
CREATE POLICY tenant_update ON data.ai_prompt_templates FOR UPDATE TO app_rw
  USING (workspace_id = (SELECT data.current_workspace_id())) WITH CHECK (workspace_id = (SELECT data.current_workspace_id()));
CREATE POLICY tenant_delete ON data.ai_prompt_templates FOR DELETE TO app_rw
  USING (workspace_id = (SELECT data.current_workspace_id()));

-- relay_checkpoints is infrastructure state, not tenant data.
REVOKE ALL ON data.relay_checkpoints FROM app_rw, app_readonly;
GRANT SELECT, INSERT, UPDATE ON data.relay_checkpoints TO tabula_relay;

-- Append-only tables: the request path may insert but never update/delete history.
REVOKE UPDATE, DELETE ON data.base_changes, data.outbox_events, data.record_revisions FROM app_rw;

-- ----------------------------------------------------------------------------
-- 7.14.4 Logical replication publication for the relay (D11).
-- publish_via_partition_root: the relay sees one logical table regardless of daily partitions.
-- The relay creates its slot:  SELECT pg_create_logical_replication_slot('tabula_relay_<shard>', 'pgoutput');
-- ----------------------------------------------------------------------------
CREATE PUBLICATION tabula_relay_pub
  FOR TABLE data.outbox_events, data.base_changes
  WITH (publish = 'insert', publish_via_partition_root = true);
GRANT SELECT ON data.outbox_events, data.base_changes TO tabula_relay;

-- 1) lock the record and read current state
SELECT cells, computed, cell_meta, version
  FROM data.records WHERE table_id = $t AND id = $r AND deleted_at IS NULL FOR UPDATE;
-- 2) allocate the per-base sequence number (late in the tx to minimize lock hold time)
UPDATE data.base_runtime SET change_seq = change_seq + 1, last_change_at = now(), updated_at = now()
 WHERE base_id = $b RETURNING change_seq;                                   -- → $seq
-- 3) apply the cell change (+ same-record formulas computed in the app)
UPDATE data.records
   SET cells     = jsonb_set(cells, ARRAY[$slot], $value::jsonb),         -- or cells - $slot to clear
       computed  = computed || $computed_patch::jsonb,
       cell_meta = cell_meta || jsonb_build_object($slot, jsonb_build_object('seq', $seq, 'by', $user, 'at', now())),
       version   = version + 1, updated_at = now(), updated_by = $user, last_change_seq = $seq
 WHERE table_id = $t AND id = $r;
-- 4) change log + revision + outbox in the same transaction
INSERT INTO data.base_changes (base_id, seq, workspace_id, kind, ops, inverse_ops, op_count, table_ids,

VALUES ($b, $seq, $w, 'records', $ops, $inverse, 1, ARRAY[$t]::uuid[], 'user', $user, 'ui', $cmid, $schema_version);

VALUES ($w, $b, $t, $r, $seq, 'update', ARRAY[$slot::smallint], $before, $after, 'user', $user, 'ui');

### 7.16.3 Grid page on a small table (< `INDEX_SIDECAR_THRESHOLD`): compiled JSONB filter

View filter *Status = "Active" AND Amount > 1000 AND Name contains "acme" AND Tags has any of [x]*, sorted by manual order, keyset page of 200. Slots: Name=1, Status=4 (single_select), Amount=7 (number), Tags=9 (multi_select). The filter compiler ([11](11-filter-sort-group.md)) emits parameterized SQL only — never interpolated values.

```sql
SELECT r.id, r.row_number, r.manual_order, r.cells, r.computed, r.version
  FROM data.records r
 WHERE r.table_id = $1                                   -- partition pruning + PK/order index range
   AND r.deleted_at IS NULL
   AND r.cells -> '4' = to_jsonb($2::text)               -- single_select equals opt_…
   AND (r.cells -> '7')::numeric > $3                    -- number; type guaranteed by field codec
   AND strpos(lower(r.cells ->> '1'), lower($4)) > 0     -- contains (no LIKE escaping issues)
   AND r.cells -> '9' ?| $5::text[]                      -- multi_select has any of
   AND (r.manual_order, r.id) > ($6, $7)                 -- keyset cursor
 ORDER BY r.manual_order, r.id
 LIMIT 200;
-- Plan: Index Scan on records_pNN_table_id_manual_order_id_idx (table_id = $1, row comparison) + Filter.
-- Fine up to ~20k rows per table; above that the planner switches to sidecars (7.16.4).
```

Sorting by a JSONB value on a small table (no sidecar):

```sql
SELECT r.id, r.cells, r.computed, r.version
  FROM data.records r
 WHERE r.table_id = $1 AND r.deleted_at IS NULL
 ORDER BY (r.cells ->> '1') COLLATE "und-x-icu" NULLS LAST, r.id      -- Name ascending, empties last

```

### 7.16.4 Grid page on a large table using typed sidecars

Sorted by Amount (slot 7, `record_index_num`) descending, filtered by Status = opt (slot 4, `record_index_text.value_eq`):

```sql
SELECT r.id, r.row_number, r.cells, r.computed, r.version, s.value AS sort_value
  FROM data.record_index_num s
  JOIN data.records r ON r.table_id = s.table_id AND r.id = s.record_id
 WHERE s.table_id = $1 AND s.field_slot = 7 AND s.ord = 0
   AND (s.value, s.record_id) < ($cursor_value, $cursor_id)            -- keyset (DESC)
   AND r.deleted_at IS NULL
   AND EXISTS (SELECT 1 FROM data.record_index_text t
                WHERE t.table_id = $1 AND t.field_slot = 4 AND t.value_eq = $2 AND t.record_id = s.record_id)
 ORDER BY s.value DESC, s.record_id DESC
 LIMIT 200;
-- Records with empty Amount have no sidecar row; they are appended after the last page by an anti-join
-- (06 §13.5): … WHERE NOT EXISTS (SELECT 1 FROM data.record_index_num s WHERE s.table_id=$1 AND s.field_slot=7 AND s.record_id=r.id)
```

### 7.16.5 Link cells for a page of records

```sql
-- Forward side (A) of relation $rel for the visible records, in cell order:
SELECT l.a_record_id, l.b_record_id
  FROM data.record_links l
 WHERE l.relation_id = $rel AND l.a_record_id = ANY($page_ids::uuid[]) AND l.deletion_batch_id IS NULL
 ORDER BY l.a_record_id, l.a_order;
-- Primary-field labels of the targets (one batched fetch per target table):
SELECT id, cells -> $primary_slot AS label, computed -> $primary_slot AS clabel
  FROM data.records WHERE table_id = $target_table AND id = ANY($target_ids::uuid[]);
```

### 7.16.6 Realtime / webhook catch-up

```sql
SELECT seq, id, kind, ops, actor_type, actor_id, via, client_mutation_id, created_at
  FROM data.base_changes
 WHERE base_id = $1 AND seq > $2
 ORDER BY seq
 LIMIT 500;
-- Probes the PK index of each of ≤ 30 daily partitions (cheap). If $2 < min retained seq → client resyncs.
```

### 7.16.7 Lookup by public ID in a time-partitioned table (partition pruning via UUIDv7 time)

SELECT * FROM data.automation_runs
 WHERE id = $1
   AND trigger_at BETWEEN public.uuidv7_time($1) - interval '7 days' AND public.uuidv7_time($1) + interval '1 minute';
-- run ids are generated at insert time ≥ trigger_at, so the window is (trigger_at ≤ id time).

### 7.16.8 Queue-style claims (`SKIP LOCKED`)

```sql
-- Deferred recompute
WITH batch AS (
  SELECT table_id, record_id, field_id FROM data.computed_stale
   WHERE base_id = $1 ORDER BY enqueued_at LIMIT 500 FOR UPDATE SKIP LOCKED)
DELETE FROM data.computed_stale c USING batch b
 WHERE c.table_id = b.table_id AND c.record_id = b.record_id AND c.field_id = b.field_id
RETURNING c.table_id, c.record_id, c.field_id;      -- recomputed in the same tx; on failure re-inserted with attempts+1

-- Scheduled automations due
SELECT automation_id, automation_version_id, next_fire_at FROM data.automation_schedules
 WHERE status = 'active' AND next_fire_at <= now()
 ORDER BY next_fire_at LIMIT 500 FOR UPDATE SKIP LOCKED;
```

### 7.16.9 Trash restore of a record batch (sketch; semantics in [22](22-audit-history-undo-trash.md))

```sql
UPDATE data.records      SET deleted_at = NULL, deleted_by = NULL, deletion_batch_id = NULL, version = version + 1
 WHERE table_id = $t AND deletion_batch_id = $batch;
UPDATE data.record_links SET deletion_batch_id = NULL WHERE deletion_batch_id = $batch;
UPDATE data.deletion_batches SET status = 'restored', restored_at = now(), restored_by = $user WHERE id = $batch;
-- + sidecar rebuild for restored records, base_changes 'restore' entry, outbox 'record.restored'
```
